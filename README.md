# Wonderland Auth Core

**A reusable Python authentication library for developers, freelancers, and small software teams.**

**Current version:** `0.1.0rc7` (release candidate)  
**Developer:** Wonderland Developer Tools — independently developed in Thailand

## Overview

Authentication involves more than a login form. Password hashing, session lifecycle management, account controls, and persistence need clear boundaries.

Wonderland Auth Core provides a reusable foundation for developers integrating essential authentication functionality into their own Python applications. Licensed distributions include source code, documentation, and automated tests.

## Key Features

- **Argon2id password hashing** — Password hashing and verification.
- **Session lifecycle management** — Session creation, validation, expiration, and revocation.
- **Secure token handling** — Random session tokens and digest-based storage.
- **Account controls** — Account management and disabled-account enforcement.
- **SQLite persistence** — Authentication data storage with transaction safeguards.
- **Developer resources** — Source code, configuration guidance, and automated tests in licensed packages.

## Validated Environment

The documented validation environment for version `0.1.0rc7` is:

- Windows x64
- CPython 3.14.6

Other operating systems and Python versions have **not** been validated for this release. Developers should test compatibility and security in their intended environment.
